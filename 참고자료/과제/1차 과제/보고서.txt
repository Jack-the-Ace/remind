보고서

본 과제에서는 ResNet50을 최종 사전학습 모델로 선정하였다. 수업에서 학습한 ResNet152와 동일한 계열로 기존에 습득한 코드를 최대한 재활용할 수 있으며, ResNet152보다 파라미터 수와 연산량이 적어 제한된 과제 수행 시간 내에 효율적으로 학습할 수 있다고 판단하였다.

문제 해결 프로세스
1. 문제 정의
   
   자동차 사진만 보고 제조사와 차종을 구분하고 싶었다.
   
   이미지 분류 문제로 정의
2. 데이터 수집 및 분석
   
   Kaggle에서 자동차 이미지 데이터셋을 수집하고 클래스별 이미지 수와 분포를 분석했다.
   
   데이터셋을 먼저 이해해야 적절한 모델을 선택할 수 있기 때문
3. 모델 탐색
   
   여러 CNN 모델을 비교하고 ResNet 계열을 선택했다.
   
   수업에서 배운 모델을 재사용하고 제한된 실행 시간도 고려
4. 전이학습 전략 결정
   
   기존에 학습된 특징 추출기는 유지하고 마지막 분류층만 자동차 클래스에 맞게 교체했다.
   
   데이터 규모와 사전학습 모델의 시각적 유사도를 고려
5. 학습 및 평가
   
   Train / Validation / Test를 구분하여 학습과 최종 평가를 수행했다.
   
   학습에 사용하지 않은 이미지로 일반화 성능 확인
6. 실제 활용
   
   새 자동차 사진을 입력해 브랜드와 모델을 예측하는 기능을 구현했다.
   
   학습 결과를 실제 사용 가능한 기능으로 연결
