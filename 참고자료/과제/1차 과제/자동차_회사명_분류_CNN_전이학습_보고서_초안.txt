1. 과제 개요
============================================================

1-1. 프로젝트 주제
자동차 사진을 입력하면 이미지에 나타난 자동차의 제조사(회사명)를 분류하는 CNN 전이학습 모델을 구현한다.

1-2. 문제 정의 및 구현 범위
이번 데이터셋은 Train 폴더와 Test 폴더로 나뉘어 있으며, 각 폴더 안에 동일한 7개 자동차 제조사 폴더가 존재한다. 이미지 파일명은 숫자로 되어 있고, 개별 자동차의 모델명 또는 차종을 나타내는 별도 라벨은 제공되지 않는다.

따라서 현재 데이터셋으로 학습할 수 있는 정답은 자동차 제조사 7개뿐이다. 파일명의 숫자는 이미지 식별용 이름으로 취급하고, 자동차 모델명이나 세부 차종을 의미한다고 해석하지 않는다. 본 과제의 분류 결과도 제조사명까지만 출력하도록 범위를 정한다.

새로운 자동차 사진을 입력하면 다음 두 가지를 화면 또는 출력창에 표시하는 것을 목표로 한다.
  ① 예측한 자동차 제조사명
  ② 해당 예측 클래스에 대한 모델의 예측 신뢰도(Confidence, %)

여기서 이미지 한 장에 표시되는 Confidence(%)와 Test 데이터 전체에 대한 Accuracy(%)는 서로 다른 개념이다. Confidence는 모델이 해당 입력을 특정 클래스로 얼마나 강하게 예측했는지를 나타내는 점수이며, 그 사진의 실제 정답률을 보장하지 않는다. Accuracy는 정답 라벨이 있는 별도의 Test 이미지 전체에서 모델이 맞힌 비율이다. 따라서 보고서의 성능 평가는 Test Accuracy와 Precision, Recall, F1-Score 등으로 제시하고, 새 사진 결과에는 예측 신뢰도라고 표기한다.

1-3. 프로젝트 선정 동기 및 향후 활용 구상
본 과제는 CNN 이미지 분류와 전이학습을 처음 적용해 보는 실습 프로젝트이다. 자동차는 외형, 전면부 디자인, 램프, 그릴 등 시각적 특징을 가지고 있어 이미지 분류의 대상이 될 수 있다. 또한 향후 구상 중인 '음주운전 방지 및 신고 앱'에서 차량 관련 정보를 정리하는 보조 기능으로 확장할 가능성이 있다고 생각하여 자동차 이미지 분류를 주제로 선정하였다.

다만 이번 과제의 구현 범위는 자동차 제조사 분류에 한정한다. 자동차 제조사를 알아내는 기능만으로 음주운전 여부를 판단하거나 차량을 실시간 추적할 수 있는 것은 아니다. 향후 앱에 적용하려면 신고자의 위치·촬영 시각 등 추가 정보, 차량번호 또는 차량 식별 기능, 통신 및 관제 시스템 연동, 오인식에 대한 사람의 확인 절차, 개인정보 및 관련 법령 검토 등이 별도로 필요하다. 이번 결과는 그러한 서비스 전체가 아니라, 사진에서 차량의 시각적 정보를 추출하는 기초 기술을 실험하는 단계이다.

데이터 분포 분석:

데이터 분할 계획:

3. 2단계: 사전학습 모델 탐색 및 선정 (Q2)
============================================================

3-1. 사전학습 CNN 모델 비교 (Q2-1)

① ResNet
- 잔차 연결(Residual/Skip Connection)을 이용하는 CNN 구조이다.
- 깊은 신경망에서 학습이 원활하게 이루어지도록 돕는다.
- ResNet18, ResNet50, ResNet152 등 여러 깊이의 모델이 있다.
- 수업에서 ResNet152를 이용한 전이학습 및 모델 불러오기를 학습했으므로 기존 수업 코드와 연결하기 쉽다.

② VGG
- 3×3 합성곱 층을 여러 개 쌓는 비교적 직관적인 구조이다.
- 구조가 이해하기 쉽지만, 모델에 따라 파라미터 수와 메모리 사용량이 큰 편이다.

③ MobileNet
- Depthwise Separable Convolution 등 연산량을 줄이는 구조를 사용한다.
- 모바일 기기나 연산 자원이 제한된 환경에서 활용하기 적합한 경량 모델 계열이다.

④ EfficientNet
- 네트워크의 깊이, 너비, 입력 이미지 해상도를 균형 있게 조정하는 방식으로 설계되었다.
- 모델 크기와 성능의 균형을 고려할 수 있으며 여러 규모의 모델이 제공된다.

3-2. 최종 모델 선정 및 이유 (Q2-2)
본 과제의 기본 모델은 ImageNet으로 사전학습된 ResNet50으로 선정한다.

선정 이유:
첫째, 수업에서 ResNet152를 사용해 모델을 불러오고 마지막 분류층을 교체하는 방법을 배웠기 때문에 ResNet50을 사용하면 수업에서 배운 코드 구조를 최대한 재활용할 수 있다.
둘째, ResNet50은 ResNet152보다 상대적으로 가벼워 제한된 과제 수행 시간과 하드웨어 환경에서 실험하기에 유리하다.
셋째, ImageNet 사전학습 모델이 학습한 일반적인 시각적 특징을 자동차 이미지에도 활용할 수 있다고 판단하였다. 다만 이번 과제는 자동차의 세부 모델명을 구분하는 것이 아니라 7개 제조사 중 하나를 분류하는 것이므로, 우선 제조사 분류에 필요한 특징을 학습하는 것을 목표로 한다.

ResNet50이 반드시 가장 높은 정확도를 보장하는 것은 아니다. 이번 선택은 수업 내용과의 연계성, 제한된 실행 시간, 전이학습의 구현 용이성을 고려한 1차 실험 모델 선정이다.

4. 3단계: 데이터셋 특성에 따른 전이학습 전략 및 구현 (Q3)
============================================================

4-1. 데이터 규모와 사전학습 데이터의 유사도 분석 (Q3-1)

데이터 규모:
현재 Train과 Test가 약 8:2 비율로 구성되어 있는 것은 확인했지만, 비율만으로 데이터가 많은지 적은지를 판단할 수는 없다. 전체 이미지 수와 제조사별 이미지 개수를 코드로 확인한 뒤 데이터 규모를 평가한다. 특히 전체 이미지 수뿐 아니라 제조사별 이미지 수가 얼마나 균등한지도 함께 고려한다.

사전학습 데이터와의 유사도:
ImageNet 사전학습 모델은 다양한 사물과 자연 이미지의 시각적 특징을 학습하였다. 자동차도 일반적인 물체 이미지라는 점에서 윤곽, 색상, 질감, 부품 형태 등 공통적인 시각 특징을 활용할 수 있다. 반면 이번 과제는 자동차인지 아닌지를 구분하는 것이 아니라 자동차의 제조사별 차이를 구분해야 한다. 제조사 간 차이는 전면 그릴, 헤드램프, 엠블럼, 차체 디자인처럼 세밀한 특징에 있을 수 있으므로, 일반적인 ImageNet 분류와 완전히 동일한 문제는 아니다. 따라서 시각적 영역은 유사하지만 분류 목적은 더 세밀한 문제라고 판단한다.

선택한 초기 전략:
과제 수행 시간과 데이터 규모를 아직 정확히 확인하지 못한 상황이므로, 먼저 사전학습된 ResNet50의 기존 특징 추출층을 동결하고 마지막 FC(Classifier) 층만 자동차 제조사 7개 클래스에 맞게 교체하여 학습한다. 이는 기존의 유용한 특징 추출 능력을 유지하면서 새 데이터셋의 정답 라벨에 맞는 분류기를 학습시키는 기본 전이학습 전략이다.

실제 데이터가 충분하고 Validation 성능이 FC 층 학습만으로 개선되지 않는다면, 추가 실험으로 ResNet의 마지막 블록(layer4) 일부를 학습 가능하게 풀어 미세조정하는 방법을 고려한다. 두 전략을 비교할 경우 동일한 Test 데이터로 반복해서 전략을 선택하지 않고, Validation 결과를 중심으로 설정을 결정한 뒤 최종 Test 평가는 마지막에 수행한다.

[전략 판단 기록]
- 실제 전체 이미지 수: [실행 후 입력]
- 제조사별 최소/최대 이미지 수: [실행 후 입력]
- 초기 전략: 특징 추출기 동결 + FC 층 학습

4-2. 모델 학습 구현 요약 (Q3-2)

① 이미지 전처리
- 자동차 이미지를 RGB 형식으로 통일한다.
- ResNet50 사전학습 가중치에 맞는 입력 크기와 정규화 전처리를 적용한다.
- 학습용 데이터에는 필요에 따라 좌우 반전 등 적절한 데이터 증강을 적용할 수 있다. 단, 실제 코드에 적용한 증강만 보고서에 기재한다.

② 데이터 로딩
- 제조사 폴더명을 클래스 라벨로 사용한다.
- Dataset 클래스로 이미지와 라벨을 읽는다.
- DataLoader를 이용하여 미니배치 단위로 모델에 전달한다.

- 마지막 FC 층만 requires_grad=True로 설정하여 학습한다.

④ 학습 설정
- 손실함수: CrossEntropyLoss

부록 A. 데이터 이미지 개수 확인용 코드
============================================================

아래 코드는 DATA_DIR을 Train과 Test 폴더가 들어 있는 최상위 폴더로 지정한 경우 사용하는 예시이다. 실제 폴더명이 다르면 경로를 수정한다. 이 코드를 실행해 나온 숫자를 2-3절의 표에 입력한다.

from pathlib import Path

DATA_DIR = Path(r"D:\실제\자동차\데이터셋\경로")

image_ext = {".jpg", ".jpeg", ".png", ".bmp", ".webp"}

for split_name in ["train", "test"]:
    split_dir = DATA_DIR / split_name
    print("\n", split_name.upper())

    if not split_dir.exists():
        print("폴더를 찾을 수 없습니다:", split_dir)
        continue

    total_count = 0
    for class_dir in sorted(split_dir.iterdir()):
        if class_dir.is_dir():
            count = sum(
                1 for file in class_dir.rglob("*")
                if file.is_file() and file.suffix.lower() in image_ext
            )
            total_count += count
            print(class_dir.name, ":", count, "장")

    print("전체:", total_count, "장")

※ 폴더명이 실제로 Train, Test처럼 대문자로 되어 있다면 코드의 ["train", "test"]도 실제 이름에 맞게 수정한다.
