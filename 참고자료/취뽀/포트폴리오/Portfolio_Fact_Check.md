## 3. OLIGO-K의 개인 기여와 팀 범위

### 본인 기여로 제시한 내용

아래 항목은 이력서 p4의 `[역할]`에 명시돼 있다.

- React 기반 프론트엔드 전담

- Day/Night 모드

- 공모전 제출서류·서비스 매뉴얼 작성 및 제출
- 최종 배포

이 중 현재 공개 브라우저에서 직접 확인한 것은 홈·대시보드 표시, Day/Night 전환, PC·모바일 레이아웃이다. **계정 기능, 과거 개선 과정, 코드 작성자, 최종 배포 담당 여부는 이력서와 제공 자료에 근거**한다. 코드 저장소의 기여 이력이나 일반 사용자 로그인 테스트로 별도 검증한 것은 아니다.

### 팀 서비스 범위로 제시한 내용

관광 데이터 수집·분석, 관광 지표 예측, 생성형 AI의 전략 기획안 작성, 백엔드·데이터베이스, Word/PPT 문서 생성은 팀 프로젝트의 서비스 구조로 설명했다. 이를 지원자가 혼자 개발한 것으로 표현하지 않았다.

매뉴얼 p4의 팀 기술 구조는 React/Vite/JavaScript/CSS, Python/FastAPI, OpenAI API, MySQL, AWS, VS Code/Git/GitHub로 정리된다. 기술명을 나열했다는 이유만으로 모든 기술의 개인 실무 숙련도를 주장하지 않는다.

### 설계 해석과 후속 제안의 구분

- 사용자 여정과 콘텐츠 흐름 다이어그램은 매뉴얼 내용을 읽기 쉽게 재구성한 **설명 도식**이다. 제품 화면 캡처가 아니다.
- 실제 화면에서 확인되는 구조를 설명하는 문구는 관찰 가능한 범위에 한정한다. 당시 수행한 사용자 조사나 A/B 테스트로 확대하지 않는다.
- 후속 검증, AI 결과 검토 기준, 운영 시 확인 항목은 **제안 또는 업무 원칙**이다. 이미 실행해 효과가 입증된 활동으로 제시하지 않는다.

## 4. Excel 성과 계산 검증

원문: 이력서 p2의 재고현황파악 자동화 프로젝트. 수행 기간은 **2020-11-01~2020-12-01**로 기재돼 있다.

| 항목 | 계산/값 |
|---|---|
| 기존 소요시간 | 약 2시간 = 7,200초 |
| 개선 후 소요시간 | 약 2분 40초 = 160초 |
| 절감 시간 | 7,200 - 160 = 7,040초 = 117분 20초 |
| 소요시간 감소율 | (7,200 - 160) ÷ 7,200 × 100 = 97.777…% |
| 본편 표현 | **소요시간 약 97.8% 감소** |

감소율은 원문 시간에 근거한 **계산치**다. 새로운 실험이나 추가 측정 결과가 아니다. 이력서의 시간 자체가 근삿값이므로 감소율도 '약'을 사용한다.

'효율 97.8% 향상'처럼 분모가 불명확한 표현, 연간 절감시간, 인건비 절감액, 오류율 개선은 사용하지 않았다. 원자료 수, 작업 범위, 반복 측정 횟수, 비교 조건은 제공 자료만으로 확인할 수 없다.

재직처는 **신화다이나믹스**로 기재돼 있으나 사례 설명에는 **신화실업(주)**이 파일을 사용하는 조직으로 나온다. 양사의 관계는 확인되지 않았다. 최종본은 자동화 문제와 본인 수행 과정에 집중했으며 두 회사의 법적 관계를 추정하지 않았다.

이력서에 있는 '현재에도 사용'은 이력서 작성 시점의 진술이다. 2026년 11월 현재의 사용 여부를 재확인하지 못했으므로 현재도 계속 사용 중이라고 단정하지 않았다.
