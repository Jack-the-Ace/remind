## 완성본의 구성 의도

원본 20장을 14장으로 재편집했다. 경력·강점·교육·기술을 길게 소개한 뒤 프로젝트를 보여주던 흐름을 바꾸어, 초반에 대표 경험을 제시하고 OLIGO-K를 가장 깊게 설명하도록 구성했다. 약 8년의 실무 경험은 마케팅·영업·운영·문서화 경험으로 표시하고, IT 영역의 경험은 AI+X 교육과 프로젝트 수행 범위로 구분했다.

포지셔닝의 중심은 현장의 문제를 이해하고, 정보를 구조화하며, 화면 구현과 문서화까지 연결하는 기획자다. 시니어 개발자나 AI 모델 전문가라는 인상을 만들기보다, AI 콘텐츠·서비스 기획 업무에 연결되는 실제 행동과 산출물을 보여주는 데 집중했다.

## 삭제·축소한 내용

- 생년월일·나이·성별·상세 거주지, 건강·의료 및 사적 생활 서술, 과거·희망 연봉.
- 평생직업·장기 근속 등의 다짐, 추상적인 자기평가, 역량을 반복해서 설명하는 문장.
- 기술별 숙련도 그래프나 실제 사용 범위를 확인할 수 없는 전문성 주장.
- 출처가 충분하지 않은 OLIGO-K의 ‘250+ 시·군·구’, ‘7개 관광지표’ 수치.
- 실제 방문자·지역매출 증가처럼 오해될 수 있는 기대효과의 성과화.
- 캠페인 수·매출·ROAS·CTR 등 제공 자료에 없는 마케팅 지표.
- 아직 구현하지 않은 게임·앱 아이디어, 빈 이미지 박스, 작성 안내 문구, 미확인 GitHub 링크.
- 현재 지속 사용 여부를 확인하지 못한 Excel 파일의 ‘지금도 사용 중’ 단정.

캐나다 매장 운영과 스타트업 경험은 핵심 사례보다 비중을 낮췄다. 다양한 일을 했다는 사실 자체보다 고객·현장·운영·문서를 이해한 경험이 새 직무에서 어떤 역할을 할 수 있는지에 초점을 맞췄다.

## 새로 보강한 내용

- OLIGO-K의 사용자·문제·서비스 목적과 콘텐츠 생성 흐름.
- 원본 PPT에 없던 제공 매뉴얼의 구체적인 입력·미리보기·출력 화면.
- 현재 배포 사이트의 Day/Night 및 모바일 화면.
- 팀 서비스 구조와 본인 기여의 명시적인 경계.
- Excel의 수치 비교와 계산 근거. 2시간을 7,200초, 2분 40초를 160초로 환산하면 감소율은 `(7,200-160)/7,200×100 ≈ 97.8%`다. 원본의 약값을 바탕으로 계산한 소요시간 감소율이며 별도 실험 결과가 아니다.
- 실제로 한 일과 앞으로 검증할 일을 분리한 후속 과제.
- 직접 구현 경험과 교육에서 학습한 범위를 구분한 역량 설명.

큰 제목·수치와 충분한 여백을 사용하고, 화면 확대·주석, 흐름 도식, 역할 비교, 숫자 비교, 에디토리얼 문단을 교차 배치했다. 슬라이드마다 같은 3~4열 카드 구성을 반복하지 않도록 프로젝트 내용에 따라 레이아웃을 달리했다. ‘2시간 → 2분 40초’는 개선 규모를 즉시 이해하는 시각적 중심으로 사용한다.

16:9 와이드스크린으로 제작하며, 본문 텍스트와 주요 도형·설명 도식은 편집 가능한 요소로 구성했다. 제품 화면은 원본 이미지 또는 실제 브라우저 캡처를 사용한다. 사진·로봇·AI 두뇌 이미지와 같은 장식 이미지는 추가하지 않았다.

## 사용자가 추가하면 좋은 증빙

완성본의 빈칸을 채우기 위한 자료가 아니라, 제출 내용의 신뢰도를 높이고 면접에서 구체적인 질문에 답하기 위한 자료다.

1. **Excel 원본 또는 비식별 시연본과 측정 조건.** 같은 업무 범위에서 2시간과 2분 40초를 비교했는지 설명할 수 있는 기록. 재직처 신화다이나믹스와 사례에 등장하는 신화실업의 관계도 확인이 필요하다.
2. **OLIGO-K 실제 생성 Word/PPT 파일과 시연 기록.** 입력 조건, 생성된 초안, 수정 후 결과를 함께 확보하면 AI 콘텐츠 기획의 전달력이 높아진다.
3. **개인 기여 증거.** 역할분담표, 본인 커밋, Notion 회의록, 제출 문서와 배포 기록. 팀 인원과 정확한 프로젝트 기간도 확인하면 좋다.
4. **계정 흐름의 비식별 화면.** 회원가입·로그인·마이페이지의 실제 동작을 보여주는 캡처나 짧은 영상.
5. **공개 가능한 마케팅 산출물.** 광고주 요구 정리, 캠페인 일정·운영 문서, 결과 보고서. 수치가 확인되는 경우에만 성과 지표를 추가한다.
6. **최신 이력서와 날짜 확인.** 요청한 `이력서_20261102.pdf`는 작업 폴더에서 찾지 못해 첨부된 `변재근_이력서.pdf`를 사용했다. 원문 수정일은 2026-10-14다. 이후 변경사항과 주하이엔씨 퇴사 시점의 원문 불일치를 확인해야 한다.

실제 생성·출력 기능, 계정 기능, 정확한 역할·기간, 자동화 측정 조건은 면접 전 우선 확인할 항목이다. 이 중 확인되지 않은 내용은 현재 포트폴리오에서 검증된 성과로 확장하지 않았다.

| 5 | AI 콘텐츠 기획 직무와 가장 직접적으로 연결 | 어떤 입력이 어떤 분석·초안으로 이어지는지, 사람이 무엇을 검토해야 하는지, 실제 확인 범위는 어디까지인지 |
| 8 | 팀 프로젝트 속 개인 실행 역량을 확인 | 본인이 설계·구현한 화면과 기능, 팀의 AI·데이터 영역과의 협업 경계, 어려웠던 구현과 판단 |
| 10 | 측정 가능한 업무 개선 경험을 제시 | 약 1,000개 품목의 업무 병목, Excel 선택 이유, 전후 소요시간과 계산 기준, 관련 부서 교육 |

각 페이지는 먼저 핵심 한 문장으로 소개한 뒤 실제 사례 하나를 덧붙이는 방식이 적합하다. 측정하지 않은 성과나 기억이 불확실한 수치는 추가하지 않는다.

## 품질 자체 평가 기준과 편집 판단

아래 평가는 합격 가능성의 예측이 아니다. 구성·내용이 갖추어야 할 조건과 남아 있는 증거의 한계를 기록한 것이다.

| 평가 항목 | 검증 기준 | 이번 구성의 판단 |
| --- | --- | --- |
| 첫인상·차별화 | 지원 직무와 대표 경험을 초반에 파악할 수 있는가 | 표지와 2쪽에서 방향을 제시하고 3쪽부터 대표 사례로 진입한다. 독특함은 장식보다 현장 경험과 구현 경험의 조합에 둔다 |
| 정보 위계·가독성 | 한 장의 주요 메시지가 분명하고 본문이 이를 뒷받침하는가 | 14장 각각의 역할을 구분했다. 결과·기능·담당 범위를 한 화면에 과도하게 섞지 않는다 |
| 시각적 완성도 | 색·서체·정렬 체계가 일관되고 레이아웃이 내용에 맞게 변하는가 | 제한된 색상과 서체를 사용하고 화면·도식·숫자·역할 비교를 교차 배치하는 시스템을 선택했다 |
| AI 콘텐츠 기획 적합성 | 기술 명칭보다 입력·콘텐츠 구조·검토·사용 맥락을 설명하는가 | OLIGO-K를 사용자와 문서 생성 흐름으로 설명하고, Excel은 AI가 아닌 업무 자동화 사례로 명확히 분리한다 |
| 프로젝트 스토리텔링 | 문제·역할·접근·산출물·결과의 관계를 따라갈 수 있는가 | OLIGO-K는 서비스·화면·역할·전달 순서로, Excel은 결과·방법 순서로 구성했다 |
| 개인 기여 명확성 | 팀 기능을 개인 성과로 오인할 가능성이 없는가 | 8쪽에서 개인 프론트엔드와 팀 AI·데이터·백엔드 범위를 나눠 제시한다 |
| 실제 증거·신뢰성 | 실제 화면과 도식, 목적과 실측 결과가 구별되는가 | 제공 매뉴얼과 현재 캡처를 사용한다. AI 생성·출력의 전체 실동작과 일부 성과 증빙은 추가 확인이 필요하다 |
| 면접 활용성 | 핵심 사례를 빠르게 선택하고 추가 질문으로 연결할 수 있는가 | 5·8·10쪽을 중심으로 서비스 이해, 개인 실행, 업무 개선을 설명할 수 있다. 상세 증거는 위의 추가 자료 목록으로 보완 가능하다 |

## 폰트·이미지 사용 범위

- Malgun Gothic(맑은 고딕)과 Arial 시스템 폰트를 지정했다. 폰트 파일을 별도로 배포하지 않는다. 다른 운영체제에서 폰트가 없으면 PPTX의 줄바꿈이 달라질 수 있으므로 제출에는 PDF가 더 안정적이다.
- 외부 스톡 이미지나 생성형 장식 이미지를 새로 사용하지 않았다. 사용 화면은 제공 프로젝트 매뉴얼과 해당 프로젝트의 실제 캡처다.
- 제공 자산 및 서비스 내부의 지도·사진·데이터 등에 관한 개별 권리 관계는 독립적으로 확인할 수 없었다. 포트폴리오 작성 권한과 제3자 자산의 재배포 권한은 동일하지 않으므로, 대외 공개 범위는 프로젝트의 이용 조건과 팀 합의를 확인해야 한다.
- 연구 참고자료의 화면·레이아웃·자산을 그대로 복제하지 않았으며, 근거 링크는 이 보고서에 남겼다.
