## 설계 판단과 미검증 목표

- 주간 직선 구간부터 이진 차선 segmentation을 학습한다. 다중 색·종류 분류는 후순위지만 라벨 속성과 조건별 평가는 보존한다.
- thin line 정답은 polyline rasterization 규칙을 고정한다. lane IoU는 실제 도색 영역 전체의 정확도와 구분한다.
- 실제 음주/위법 정답이 아니라 관측 가능한 경계 교차·반복 이동의 시간 구간을 라벨링한다.
- 600~1,200장, fallback 300장, 20~40 epoch, 70/15/15, ID 유지율 90%, lane IoU 0.50, P0.80/R0.60, 오탐 0.2건/분은 모두 제안값이다.
- 지원 조건과 전체 조건의 성능·보류율을 함께 공개하며 작은 평가셋을 실도로 성능으로 일반화하지 않는다.
- 일반 기록 7일은 제품 정책 초안이며 법정 기간이 아니다. 파기 기능 구현이나 법률 검토 완료를 주장하지 않는다.
- 11월 자동 이벤트 1종을 보존하고 OCR·음성·실제 전화·주차/신호 등은 후속으로 분리한다.
- 12월은 2PC LAN 통신과 허가된 영상 재생으로 시연한다. 카메라 간 자동 동일차량 식별이 실패하면 사람이 후보 연결을 확인한다.

## 파일 제작과 점검 방식

- @oai/artifact-tool로 1280×720(16:9) PPTX를 제작했다. 텍스트·표·도형·연결 화살표는 PowerPoint에서 편집 가능한 native object다.
- 사용자 요청에 따라 와이어프레임과 개념도는 편집 가능한 도형으로 작성했다. 사진은 새로 생성하지 않고 명시적인 이미지 교체 영역을 확보했다.
- Malgun Gothic(맑은 고딕) 사용. Windows 설치 폰트에서 malgun.ttf·malgunbd.ttf 존재를 확인했다.
- 14개 슬라이드를 PNG로 렌더링하여 각각 확인한다. 최종 검토 내용은 `산출물/검토안내_페이지구성_미확인사항.md`에 정리한다.
- 제출 PDF는 생성하지 않는다. 자료 PDF 원본을 수정하지 않는다.
- 최종화 도구의 Windows hardlink 게시가 EPERM으로 실패하여, 제작 스크립트에서 해당 경우에 한해 배타적 일반 파일 복사로 대체했다. 검증기 자체는 변경하지 않고 원래의 검증 후 SHA-256 일치 확인을 유지한다.
