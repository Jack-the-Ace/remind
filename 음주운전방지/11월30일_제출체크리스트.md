### 서비스 실행 및 소스 패키지 경로

압축을 풀어 `041_redbox_mvp.py`가 있는 디렉터리에서 PowerShell로 실행한 뒤 브라우저에서 로컬 실행 주소를 연다.

```powershell
python -B -X utf8 .\041_redbox_mvp.py --port 8770
```

- 실행용 사본에서 확인한 모델은 루트 `yolo26n.pt`(5,544,453 B), `output/lane_transfer_197_highres/imagenet_v1_640x400_recalibrated.pt`(44,315,071 B)다. 입력 예시는 `videos/비접촉_사고유발_영상_낮.mp4`(8,789,577 B)다. 웹 자산 `redbox_mvp/`, OCR 스크립트 `045_read_korean_plate.ps1`, 실행에 필요한 Python 모듈과 빠른 재생 자료도 위치를 명시한다. 재생 자료를 다른 폴더에 놓으면 `--demo-dir`를 사용한다.
- 점검 환경은 Windows, Python 3.14.5, torch 2.11.0+cu130, torchvision 0.26.0+cu130, OpenCV 5.0.0.93, Ultralytics 8.4.208, NumPy 2.5.4, Pillow 13.0.0, EasyOCR 1.7.2, SciPy 1.18.1이다. 실제 분석에 필요한 CUDA, OCR 모델 파일, 학습에 필요한 추가 라이브러리를 실행 안내에 명시하고 패키지에서 확인한다.
- 공개 저장소에는 개인 차량번호가 든 영상·로그, 데이터 원본, 대용량 가중치를 제외하고 제출용 복사본과 구분한다.
