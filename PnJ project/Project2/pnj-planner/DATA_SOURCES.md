# PnJ 데이터 출처와 검산

## 실행에 쓰는 관광 통계

서울관광재단의 2025년 외국인 최종 조사에서 **경험 활동 7개와 방문 장소 7개**를 집계했다. 앱은 서버에서 `backend/app/data/seoul_survey_2025.json`만 읽는다. 비교용 통합 파일, 개인별 응답, 논문은 프런트엔드에 배포하지 않는다. 자료 확인일은 2026-11-26이다. [최종 조사·원자료·보고서·통계표](https://www.sto.or.kr/survey/16119_/16119) · [2019~2025 통합 자료](https://www.sto.or.kr/survey/16086_/16086)

통합 2025년의 ID **2,423개 모두** 최종 UID에도 있으며, 이들 모두 쇼핑·음식·고궁/박물관 3개 응답 표시가 일치한다. 최종 1~5차 원표본은 1,203·1,220·1,215·1,207·1,222명이다. 첫 두 차수의 합도 2,423명이다. 공식 개인별 연계표를 확인하지 못했으므로 전체 응답 동일성을 단정하지 않는다. 두 자료를 합산하지 않고 최종본만 집계한다.

참고 이미지 `2025_서울관광실태조사_조사개요_참고.png`와 소개 페이지의 기간 설명에는 2024년이 적혀 있으나 차수별 일정은 2025년 5~12월이다. 최종 보고서와 원자료·차수표를 기준으로 조사연도를 2025년으로 확정했다. 최종 DATE 열에는 ISO 날짜와 Excel 일련번호 문자열이 섞여 있다. 두 형식을 통일한 뒤 6,067건의 실제 응답일이 2025-05-25~2025-12-16에 속함을 확인했다.

### 분모·결측·코드

- 활동은 `B1_1_1 … B1_1_23`의 복수응답 경험 항목이다. 예를 들어 쇼핑 열은 값 1, 음식 열은 값 2가 선택이다. 별도 `#2` 열의 만족 순위는 제외했다. 장소는 `E1_1 … E1_51` 중 장소가 정확히 대응하는 7개만 취했다. 통합본은 각각 B1·F1 계열이어서 열 위치를 재사용할 수 없다.
- 이 두 최종 표의 분모는 집단 전체 응답자다. 해당 열의 공란은 그 활동·장소에 표시하지 않았다는 뜻으로 분자에서만 제외한다. 다른 조건부 문항, 조사되지 않은 연도, 명칭이 모호한 복합 권역에는 이 처리를 적용하지 않는다. 복수응답률을 합계 100으로 다시 맞추지 않는다.
- 가중 참여율은 선택한 응답자의 WT 합 ÷ 동일 집단 전체 WT 합이다. 원표본 수, 선택 원표본 수, 두 가중합, 비율, 문항 ID·라벨·연도·원본 ZIP SHA-256을 JSON에 기록한다. 전체 가중분모는 **11,587,037.513**, 원표본은 **6,067**이다. 가중 사례수를 실제 조사 인원이나 관광지 방문객 집계로 읽으면 안 된다.
- 같은 ‘거주국가’ 라벨의 `SQ8_1`, `SQ8_1_1`, `SQ8_R`가 있다. 최종 보고서 PDF 10쪽은 조사상 ‘국적’을 현재 거주국 기준으로 답하도록 명시한다. `데이터_변수명.SQ8_1`의 정규화된 국가명을 사용했다. 예를 들어 자유표기 열에서 ‘일본’과 정확히 같은 문자열만 세면 885명이지만, 공식 분류는 1,085명이다. 앱에서는 선택 입력인 **현재 거주국**만 매칭한다. 국적이나 고향으로 대체하지 않는다.
- 전체, 일본 1,085명, 중국 948명, 대만 608명, 홍콩 466명의 14개 항목을 각각 검산했다. 분모 불일치나 공식 퍼센트와 0.00001%p 이상 차이가 있으면 생성이 중단된다. 지원하지 않는 거주지·공란·100명 미만 집단은 전체 기준으로 돌아간다. 100은 PnJ 운영 가설이다.
- 방문율은 비교·감사용이다. 실제 방문 기록이나 좋아요로 저장하지 않는다. 참여율만 개인 신호 동률에서 보조적으로 쓴다. 물가·식당 가격·여행자 예산·현재 인기·개인 만족 확률을 이 조사에서 산출하지 않는다.

### 다시 만들기

공식 최종 ZIP을 내려받고 통합 원자료와 통계표를 원래 폴더에 둔다. 전처리 환경에 Python과 `openpyxl`이 필요하다. 웹앱 실행에는 엑셀 라이브러리가 필요 없다. 이번에 공식 배포처에서 받은 ZIP은 비공개 `.runtime/sto-2025-final.zip`에 두었다. 서버의 정적 파일 루트는 `frontend/dist`이고 원자료 URL은 실제로 404를 반환했다.

```powershell
python -m pip install openpyxl
python tools/prepare_survey.py "../../관련자료" "C:/Downloads/2025년 서울관광 실태조사_외국인(전체).zip"
```

## 장소·날씨·행사·트렌드
